Bank Deposit System Using Java

About

This project demonstrates a simple Bank Deposit System implemented using Java and the Linked Stack data structure.

Features

- Deposit money
- Withdraw money
- Display account balance
- Store and manage transactions using Stack
- Menu-driven program using Scanner

Data Structure Used

Linked Stack

The Stack follows the LIFO (Last In, First Out) principle.

Concepts Used

- Java Programming
- Object-Oriented Programming (OOP)
- Linked List
- Stack Operations (Push and Pop)
- Classes and Objects
- Scanner for user input

Technology

Java

Purpose

To understand how a Stack data structure can be used to manage bank deposit transactions.
