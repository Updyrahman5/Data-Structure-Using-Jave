Linked Stack Implementation in Java

About

This project demonstrates the implementation of a Stack data structure using a Linked List in Java.

Features

- Push: Add an element to the stack.
- Pop: Remove the top element from the stack.
- Peek: View the top element.
- Display: Print all stack elements.
- Exit: Close the program.

Data Structure Used

Linked Stack

A Linked Stack is a Stack implemented using nodes connected through links.

It follows the LIFO (Last In, First Out) principle.

Concepts Used

- Java Programming
- Data Structures
- Stack Operations
- Linked List
- Nodes
- Classes and Objects
- Methods
- Scanner for user input

Technology

Java

Purpose

To understand how a Stack works and learn how to implement Stack operations using a Linked List.
