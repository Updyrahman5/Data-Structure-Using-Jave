Data Structure and Java Programming Assignments

About This Repository

This repository contains Java programming assignments and practical projects developed to improve programming skills and understand Data Structures and Object-Oriented Programming (OOP).

Projects

1. Multilevel Inheritance – Demonstrates inheritance in Java.
2. Linked Stack – Implements Stack using a Linked List.
3. Bank Deposit – Demonstrates a bank deposit system using Stack.
4. Student Course – Demonstrates the relationship between Students and Courses.

Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Data Structures
- Git and GitHub

Purpose

The purpose of this repository is to practice Java programming, understand data structures, and develop problem-solving skills.
