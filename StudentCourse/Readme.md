Student Course Management System

About

This project demonstrates a simple Student Course Management System using Java and Object-Oriented Programming (OOP).

Features

- Add student information
- Add course information
- Display student information
- Display course information

Classes Used

- Student: Stores student information.
- Course: Stores course information.

Concepts Used

- Java Programming
- Object-Oriented Programming (OOP)
- Inheritance
- Classes and Objects
- Constructors
- Scanner for user input

Technology

Java

Purpose

To practice Java programming and understand how inheritance and OOP concepts can be used to manage student and course information.

Author

Java Programming Student
